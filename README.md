# La Oficina · Stats

Previa de partidos para analizar líneas de jugadores: elegís un partido y ves la forma
reciente de cada jugador (tiros, tiros al arco, faltas cometidas y recibidas, etc.)
con gráficos por partido.

Es una sola página (`index.html`). Los datos se piden en vivo desde el navegador a la
API pública de ESPN; no hay servidor ni base de datos.
